## Handlebars / annotation

### 패널은 위젯 "생성 시 1회" 빌드 — 코드 수정해도 기존 위젯엔 반영 안 됨
- **증상**: 코드에서 `@label`·필드 순서·그룹·`@default` 값을 바꿔도 기존 위젯 패널이 그대로.
- **원인**: imweb은 위젯 **처음 만들 때** annotation으로 패널을 1회 구성하고, 이후 코드 저장은 **렌더(HTML/CSS 시각)만** 갱신. 패널 스키마·저장된 값은 안 건드림(저장 데이터 보호).
- **무엇이 반영되나**:
  - CSS **규칙**(레이아웃·padding·flex 등) → 재붙여넣기로 ✅
  - `@default` **값**, `@label`, 필드 **순서/그룹**, 필드 추가 → 기존 위젯 ❌
- **해결**: 값은 **패널에서 직접** 변경. 새 라벨/순서/필드를 패널에 보려면 **새 위젯으로 생성**. `@default`는 "미래의 새 위젯/새 아이템 초기값"일 뿐.
- **item 디폴트 한계**: `@default`는 필드당 값 1개 → item 12개에 서로 다른 이름 미리 못 채움(§8.7). 차별화된 프리필 필요하면 item 대신 **고정 textfield 슬롯**(각자 @default).
