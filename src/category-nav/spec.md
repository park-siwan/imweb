# 카테고리 네비게이션 위젯 spec

> 의도 레이어. `imweb` 스킬이 이 spec를 읽고 `index.{html,css,js}`를 생성·수정한다.
> 슬라이더와 **별도 위젯**이라 자기만의 `item` 타입을 쓸 수 있다(슬라이더의 item 제약과 무관).

## 1. 용도

올리브영식 카테고리 네비게이션. **반응형 하나의 위젯**으로 기기별 형태가 다르다.
- **데스크탑**: 좌측 세로 레일. 슬라이더 위에 **오버레이**(반투명 배경)로 얹고, 각 항목 **호버 시 우측으로 펼쳐지는 서브메뉴 플라이아웃**(서브카테고리 + MD's Pick 추천 카드).
- **모바일**: 카테고리 **이미지 타일 그리드**(`cat-image`).

## 2. 패널 설정 (annotation)

**카테고리 목록 (`item-menu`, 1종, 기본 6개)**
- `label` / `link` — 카테고리명 + 링크.
- 서브메뉴: **고정 슬롯 6개** `sub1-label`/`sub1-link` … `sub6-label`/`sub6-link`.
  비어있는 슬롯은 렌더 안 됨. 서브가 하나도 없으면 플라이아웃 자체가 안 뜸.
  (imweb은 item 중첩 불가 → 평면 고정 슬롯으로 서브메뉴 구현. 슬롯 수는 20필드 한도 내에서 조정 가능.)

**스타일 토큰 (CSS 탭)**
- `text-menu-width`(폭, 기본 230) · `text-menu-font`(글자 크기) · `text-item-py`(항목 상하 여백)
- `color-menu-bg`(반투명 배경) · `color-menu-text` · `color-menu-hover`(호버 배경)
- `color-sub-bg`(플라이아웃 패널 배경) · `color-sub-text`

## 3. 동작

- **플라이아웃**: 항목 hover/focus 시 서브메뉴를 우측(`left:100%`)으로 펼침. **CSS만으로** 처리
  (`:has(.iw-sub-link)`로 서브 있는 항목만). 서브 없는 항목은 안 펼쳐지고 링크로 바로 이동.
- **터치/모바일**: hover 없음 → 첫 탭은 서브메뉴 토글(`data-open`), 다시 탭하면 링크 이동(JS).
  모바일에선 서브메뉴를 우측 플라이아웃이 아니라 항목 아래 인라인으로 펼침.

## 4. 반응형

- PC: 폭 `text-menu-width`, 우측 플라이아웃.
- 모바일(≤960px): 메뉴 폭 100%, 서브메뉴 인라인 토글.

## 5. 접근성

- `<nav aria-label="카테고리">`, 링크는 의미 텍스트.
- `:focus-within`으로 키보드 포커스 시에도 플라이아웃 노출.

## 6. 비목표

- 다단계(서브의 서브) 중첩 — imweb item 평면 구조상 미지원, 1depth 서브까지만.
- 슬라이더와의 겹침/위치 — 메뉴 위젯은 패널만 렌더, 오버레이 배치는 에디터 섹션에서.
- **`≡ 카테고리` LNB(클릭→메가패널) — 별도 위젯(`src/lnb/`)으로 분리.** 상호작용 모델·다단계 데이터가 이 레일과 달라 한 위젯에 합치지 않는다. 이 위젯은 항상 보이는 카테고리 레일만 담당.
