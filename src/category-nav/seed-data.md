# 메뉴 위젯 시드 데이터 (복붙용)

> imweb은 코드 재저장 시 배치 위젯의 item 데이터가 날아갈 수 있다(learnings 참조).
> 코드 확정 후 이 시트를 보고 한 번에 입력한다. 재입력도 여기서 복붙.
