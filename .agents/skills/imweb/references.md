# 공식문서 레퍼런스 (아임웹 Widget Studio)

스킬(`widget-generator`)이 stale해 보이거나 권위 있는 스펙 재확인이 필요할 때 참조한다.

**사용 규칙**

- 본문 복붙 금지 — 링크와 한줄요약만 유지한다. 실제 내용은 필요할 때 WebFetch로 끌어온다.
- 스킬 규칙과 문서가 충돌하면, 문서를 WebFetch로 직접 확인한 뒤 차이를 `learnings.md`에 기록한다.
- "각 3만 자"(문서) vs "약 15,000자 권장"(SKILL.md §1·§8.6)은 **다른 층위**다: 문서는 서버 상한(추정), 스킬은 품질 권장 한도. 충돌 아님.

## 코드 위젯 vs 커스텀 위젯 — 언제 무엇

우리 위젯(슬라이더·메뉴)은 **커스텀 위젯(Widget Studio)** 전용이다(annotation·샌드박스 의존). 코드 위젯에 넣으면 주석 제거로 변수 깨지고 Free는 JS 제거됨. **단, 커스텀 위젯 한계가 클 때 코드 위젯이 그 단점을 푼다.**

| 커스텀 위젯 단점 | 코드 위젯으로 해결 |
| --- | --- |
| ~15k자 한도 | ✅ 100만자 |
| 샌드박스(fetch·window·외부 API·라이브러리 차단) | ✅ 격리 안 됨 → 실제 페이지 컨텍스트, 외부 스크립트·서버 데이터 fetch 가능 |
| 격리라 다른 요소 못 건드림(겹침·전역 효과) | ✅ 격리 안 됨 → 전역 CSS로 위치/겹침 제어 |
| 코드 재저장 시 item 데이터 리셋 | ✅ 패널 없음=하드코딩이라 리셋 없음(대신 설정 불가) |
| item 1종·중첩 불가 | ✅ raw HTML 하드코딩 |

**코드 위젯의 대가**: 설정 패널 없음(비개발자 설정 불가), 격리 안 됨(전역 스타일 침투·아임웹 업데이트 시 깨질 수 있음), 주석 제거, **Free는 JS 제거**, 서버사이드 불가, 미리보기에서만 확인.

**정석 = 하이브리드**: 설정 가능한 UI·격리 안정성 → 커스텀 위젯. >15k·외부 API·실시간 데이터·외부 라이브러리·요소 간 겹침/전역 CSS → 코드 위젯 또는 SEO·헤더 전역 코드. 우리 메뉴 겹침은 `:host` 음수마진 해킹으로 했지만, 불안정하면 전역 CSS(코드 위젯) 경로가 대안.
